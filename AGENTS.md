# AGENTS.md

## Objetivo
Orientar agentes e ferramentas de desenvolvimento para manter a consistência do projeto RESOLUTA FINANCE.

## Stack atual
- React + TypeScript + Vite
- Tailwind CSS
- Vitest + Testing Library
- LocalStorage para persistência inicial

## Diretrizes
- Preserve a identidade visual da marca RESOLUTA FINANCE.
- Não invente autenticação, pagamentos ou integrações inexistentes.
- Priorize lógica financeira real, validações e cálculos transparentes.
- Documente limitações quando a persistência ou infraestrutura for inicial.
- Seja claro com estados vazios, erro e sucesso.

## Fluxo de trabalho
- Trabalhe em branch específica antes de implementar.
- Crie testes para comportamentos críticos.
- Evite “simulações” de funções que não existem.
