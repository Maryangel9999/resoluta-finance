# Contribuindo

## Fluxo de desenvolvimento
1. Crie uma issue com o objetivo e critérios de aceitação.
2. Crie uma branch específica para a funcionalidade.
3. Implementa a mudança.
4. Execute testes e validações locais.
5. Abra um pull request com descrição dos impactos e limitações.

## Padrões
- Use TypeScript e componentes reutilizáveis.
- Centralize cálculos financeiros em utilitários.
- Mantenha o código semântico e legível.
- Use validações e mensagens de erro claras.
